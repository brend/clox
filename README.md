# clox

A code-along implementation of the clox parser and VM
described in [Crafting Interpreters](https://craftinginterpreters.com)
by Robert Nystrom.

## Building

To build the executable, `clox`, simply run

```bash
make
```

## Running

After building, execute the REPL by running

```bash
./clox
```

Execute a script by running

```bash
./clox test/hello.lox
```
